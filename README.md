## Databricks Certified Data Engineer Associate – Study Workspace

This is my personal learning project for Databricks DEA exam preparation.

This workspace contains notebooks, SQL, and examples to practice Databricks core skills for the DEA exam.

Attribution: Based on “Databricks Certified Data Engineer Associate – Ultimate Prep” by Ramesh Retnasamy. Credit to the author for the original structure and learning path.




### Contents
- `dea01-databricks-lakehouse-platform`: Notebooks intro, magics, DBUtils, Git demo
- `dea02-unity-catalog`: UC basics, permissions, external storage access
- `dea03-etl-with-apache-spark`: Batch ETL (JSON/CSV/JDBC), transforms, profiling
- `dea03-etl-with-apache-spark-streaming`: Structured Streaming, Auto Loader
- `dea04-delta-lake`: Transaction log, time travel, OPTIMIZE/ZORDER, VACUUM
- `dea05-delta-live-tables`: DLT pipelines and data quality expectations
- `dea06-databricks-jobs`: Bronze/Silver/Gold SQL examples for Jobs
- `dea07-databricks-sql`: Queries and dashboard artifact
- `dea08-delta-sharing-and-lakehouse-federation`: Delta Sharing and federation
